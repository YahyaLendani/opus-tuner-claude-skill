# Code of conduct

This is a small project with one maintainer. The rule is simple: be decent.

Expected:

- Criticise the code, the design or the measurement, not the person.
- Assume the other person is trying to solve a problem, not to win an argument.
- Treat "I don't know" and "I was wrong" as normal parts of the work.
- Keep issues and pull requests on topic.

Not acceptable:

- Harassment, insults, or sustained disruption.
- Publishing someone's private information.
- Sexualised or discriminatory language and imagery.
- Dismissing a report of any of the above.

## Enforcement

Report a problem privately through the repository's **Security** tab
("Report a vulnerability"), which is the only private channel this project has.
Say in the first line that it is a conduct report, not a vulnerability, so it is
not triaged as one.

The maintainer will read it, respond within a week, and may edit or delete
comments, lock threads, or block accounts. Reports are kept confidential.

This applies in issues, pull requests, and anywhere someone is representing the
project.
